대표 프로젝트

기업환경 맞춤형 정책 기반 다중서명 지갑

팀 프로젝트 (팀 십일조) · 2025.03 – 2025.06 · 종합설계1

기업이 전자지갑을 사용할 때 발생하는 보안 문제를 해결하기 위해, 다중 서명(Multi-signature) 방식을 활용한 전자지갑 시스템을 설계했습니다. 거래 금액·직급·상황에 따라 승인 조건이 달라지는 정책(Policy) 기반 승인 체계를 스마트 컨트랙트로 구현하고, Sepolia 테스트넷에 배포했습니다.

배경

  • 기업의 블록체인 기반 자산 관리 수요가 늘고 있으나, 단일 서명 지갑은 키 분실·탈취나 내부자의 부정 사용 위험에 취약합니다.
  • 단일 서명 방식은 소유자가 바뀔 때마다 키를 재분배해야 하며, 기업의 계층적 권한 체계와 잦은 인사 변경을 반영하기 어렵습니다.

목표

  • 거래 금액·직급·상황에 따라 승인 조건이 달라지는 정책 기반 다중서명 구조 구현
  • 직급별 승인 권한 관리 및 인사 변경 시 승인 구조 즉시 반영
  • 기업 결재 절차의 자동화·투명화로 보안성과 효율성을 동시에 강화

시스템 아키텍처 — Solidity 스마트 컨트랙트 4종

  • Multisig.sol — 다중서명 핵심 모듈. 거래 제안·서명 수집·임계값 검증을 담당하고, 임계값 도달 시 PolicyManager에 검증을 요청해 실행 여부를 결정합니다.
  • PolicyManager.sol — 정책 체인. Policy.sol과 Role.sol을 순차 호출해 거래 조건을 검증하고, 모든 검증이 true일 때만 승인, 하나라도 false면 자동 차단합니다.
  • Policy.sol — 거래 금액 조건을 담당합니다.
  • Role.sol — 직급별 승인자 권한을 검증합니다.

구현 및 검증 결과

  • 4개 컨트랙트를 Solidity로 개발하고 Sepolia 테스트넷 정상 배포를 확인
  • 컨트랙트 간 연동 테스트로 정책 검증–서명 확인 절차가 자동 동작함을 확인
  • 금액·직급 조건을 다르게 설정해 승인 여부가 정확히 판별되는지 검증
  • 역할·정책 정보 변경이 시스템 재배포 없이 실시간 반영되는 구조 구현

기대 효과

  • 거래 금액·직급에 따른 승인 조건 자동 판단으로 단독 결재·내부자 위험 방지
  • 정책을 사전 등록해 승인 요청·검증을 자동 수행 → 결재 속도·정확도 향상
  • 인사 이동·직급 변경 시 승인 구조 즉시 갱신
